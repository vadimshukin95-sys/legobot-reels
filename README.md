# legobot-reels

Рилсы [LEGObot](https://legobot.ru): модели LEGO Education WeDo 2.0, отрендеренные в Blender (Cycles) из деталей LDraw, с заголовками, подписями-стикерами, музыкой и логотипом.

Репозиторий публичный, потому что в публичных репозиториях GitHub Actions бесплатны. Здесь лежат только сцены роликов; платные уроки и инструкции — в закрытом репозитории.

## Сцены

- `scenes/courier` — «Робот-курьер»: червяк → 24z → ремень → кривошипы, ноги шагают по очереди, датчик расстояния останавливает робота. Инструкция бесплатно: legobot.ru/free

## Запуск

Actions → **Render reel — «Робот-курьер»** → Run workflow. Через ~40–60 минут в запуске появится артефакт `video-courier` с `robot_kurer_wedo2_reel.mp4` (ролик) и `robot_kurer_wedo2_clean.mp4` (чистый рендер).

Пробные кадры локально: `python scenes/courier/scene.py test 40,200 540 960 10` (нужны `bpy==5.2.2` и библиотека LDraw в `LDRAW_DIR`).

## Устройство

- `scenes/<сцена>/scene.py` — сцена Blender: модель из `.mpd`, анимация механизма, свет, камера.
- `scenes/<сцена>/timeline.json` — тайминги (общие для сцены, подписей и звука).
- `scenes/<сцена>/overlay.py` — заголовки и подписи поверх кадров; `proj.json` — экранные координаты точек механизма.
- `scenes/<сцена>/audio.py` → `audio.wav` — музыка и звуки, синтезированы кодом.
- `common/reel_style.py` — фирменный стиль рилсов: объёмные заголовки, стикеры, шрифт Rubik (OFL).
- `assets/logo.png` — логотип LEGObot.

Карта доставки (`tex/map.png`) нарисована скриптом `make_tex.py`.
